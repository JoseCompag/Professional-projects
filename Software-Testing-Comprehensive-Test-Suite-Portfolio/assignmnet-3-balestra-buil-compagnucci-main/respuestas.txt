a) ¿La partición para C1 (Idem. C2) satisface la propiedad de completitud?
    La partición cubre todos los posibles estados de set1 (y de set2), ya que estos pueden ser null, {} (vacío), o
    tener al menos un elemento. Esto significa que la propiedad de completitud se cumple.
    Por lo tanto, al realizar la union de cada uno de los bloques, C1 (y tambien C2) SI satisface la propiedad de
    completitud.
b) ¿La partición para C1 (idem. C2) satisface la propiedad de no solapamiento?
    Si, las particiones satisfacen la propiedad de disjointness. Ya que es disjunta, porque que null, {} y un
    conjunto con al menos un elemento son mutuamente excluyentes. No existe superposición entre estas categorías,
    lo que garantiza que no se solapan.
c) ¿La partición para C3 satisface la propiedad de completitud?
    No. Teniendo en cuenta que algunos conjuntos tienen elementos en común, pero aun así
    no satisfacen ninguna relación de subconjunto. Ejemplo: s1 = {1, 2}; s2 = {1, 3}.
d) ¿La partición para C3 satisface la propiedad de disjointness?
    No. Considerando s1 y s2 = el mismo conjunto, como {1, 2}. Se satisfacen los predicados para
    cada uno de los primeros tres bloques, pero no para el cuarto.
e) Revise las características para eliminar cualquier problema que encuentre.
    Para resolver los problemas en C3, podemos agregar un bloque adicional que represente la relación de los conjuntos
    que tienen algunos elementos en común, pero no son subconjuntos ni iguales.
    Este nuevo bloque resolvería los problemas tanto de completitud como de disjointness.
