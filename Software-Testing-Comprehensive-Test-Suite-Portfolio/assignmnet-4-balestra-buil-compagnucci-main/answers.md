Para resolver este ejercicio, instrumentamos el código del método fmtRewrap y desarrollamos un método llamado 
getPathForRewrappedString(String string, int N) que, dados una cadena de entrada s y un número N, devuelve el

Luego, utilizamos la herramienta Graph Coverage Web Application para obtener los requisitos de test
necesarios para la cobertura de caminos principales. Estos requisitos fueron almacenados en un 
archivo CSV: src/main/java/assignment4_exercises/fmt_rewrap/csv_files/testsRequirementsForPrimePathCoverage.csv.

Implementación de la Clase BestEffortTouringTestDrive:
Desarrollamos la clase BestEffortTouringTestDrive para ejecutar nuestros tests, calcular los caminos que recorren, 
y verificar cuántos requisitos de tests se satisfacen para lograr la cobertura de caminos principales:

- Se lee el archivo CSV que contiene los requisitos de tests para cobertura de caminos principales que deben cubrirse.
- Para cada conjunto de parámetros en los casos de tests, se obtiene el recorrido en el 
- grafo utilizando el método getPathForRewrappedString.
- Se compara el recorrido de cada test con los requisitos de caminos principales, verificando cuántos de estos 
- caminos son cubiertos.
- Se cuenta cuántos requisitos de tests no son cubiertos por los caminos de los tests, y se muestra este número. 

Cabe aclarar, que no todos los requisitos de tests para cobertura de caminos principales fueron cubiertos por los
caminos de tests proporcionados. Por lo tanto, se necesitarían más caminos de tests para lograr la cobertura de
caminos principales.

medición de cobertura.

Los resultados muestran cuántos requisitos de test fueron cubiertos, y mediante JaCoCo,
